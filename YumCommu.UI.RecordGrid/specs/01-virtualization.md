# 仮想化エンジン仕様（草稿）

## 1. 目的

仮想化エンジンは、一覧の行数、行高、スクロール位置、ビューポートの高さから、ビューポートに表示する行の範囲を計算する。

この仕様では、行範囲と行位置の計算だけを扱う。データの取得、セルの生成・描画、入力操作、スクロールバーの表示は対象外とする。

## 2. 用語

| 用語 | 意味 |
|---|---|
| 行インデックス | 0 から始まる行の番号 |
| 既定行高 | 個別の行高が指定されていない行に使う高さ |
| 個別行高 | 特定の行に設定された高さ |
| スクロールオフセット | 一覧の先頭からビューポート上端までの距離。単位は DIP |
| ビューポート高 | 行を表示できる領域の高さ。単位は DIP |
| 行内オフセット | 最初に返す行の上端から、ビューポート上端までの距離 |

## 3. 入力と制約

- 総行数は 0 以上とする。
- 既定行高および個別行高は、有限かつ 0 より大きい値とする。
- 個別行高の行インデックスは、現在の総行数の範囲内（`0 <= index < TotalRowCount`）とする。
- スクロールオフセットは有限値とする。負の値は 0 として扱う。
- ビューポート高は有限かつ 0 以上とする。
- 無効な総行数、行インデックス、行高、または非有限値が指定された場合は `ArgumentOutOfRangeException` を送出する。

## 4. 行高と総高

- 個別行高が設定された行には個別行高を使い、それ以外の行には既定行高を使う。
- 総高は、全行の行高の合計とする。
- 既定行高を変更しても、個別行高が設定された行の高さは変わらない。
- 総行数が減少した場合、範囲外になった行の個別行高設定は破棄する。
- 総行数が増加した場合、追加された行には既定行高を使う。

## 5. 表示範囲の計算

表示範囲の計算結果は、次の値を持つ。

| 値 | 意味 |
|---|---|
| `StartIndex` | 表示範囲の先頭行。範囲に含む |
| `EndIndex` | 表示範囲の終端。範囲に含まない |
| `OffsetWithinFirstRow` | 先頭行の上端からビューポート上端までの距離 |

行範囲は半開区間 `[StartIndex, EndIndex)` とする。たとえば `[2, 5)` は行2、3、4を表す。表示範囲には、ビューポートと高さが重なる行だけを含める。行境界にちょうど一致する場合、境界の直前の行は範囲に含めず、次の行から開始する。

スクロール位置は、次の範囲に補正してから計算する。

```text
0 <= EffectiveScrollOffset <= max(0, TotalHeight - ViewportHeight)
```

`OffsetWithinFirstRow` は、先頭行の上端がビューポート上端より上に隠れている距離とする。描画時に先頭行を配置する Y 座標は `-OffsetWithinFirstRow` となる。結果は `0` 以上、先頭行の高さ未満とする。

## 6. 境界条件

| 条件 | 期待する結果 |
|---|---|
| 総行数が 0 | 空範囲 `[0, 0)`、行内オフセット 0 |
| スクロールオフセットが負 | オフセット 0 と同じ結果 |
| スクロールオフセットが最大位置を超える | 最大スクロール位置に補正した結果 |
| オフセットが行境界と一致する | その境界から始まる行を先頭とし、行内オフセット 0 |
| ビューポート高が 0 | 空範囲を返す |
| ビューポート高が総高以上 | 全行を含む範囲を返す |
| 表示領域の下端が行境界と一致する | 下端の境界から始まる行は含めない |

## 7. 仮想化の要件

- 戻り値は表示範囲のインデックス情報であり、行データや UI 要素を生成しない。
- 呼び出し側は戻り値の範囲に属する行だけを描画対象にできる。
- オーバースキャン（画面外の行を先読みして描画する機能）は初版の対象外とする。

## 8. テスト観点

- 既定行高での先頭・中間・末尾の表示範囲
- 個別行高を含む場合の総高、開始行、終端行、行内オフセット
- 負のオフセットおよび最大スクロール位置を超えるオフセット
- 行境界ちょうどのオフセットとビューポート下端
- 空データ、0 高ビューポート、ビューポートが総高以上の場合
- 総行数の変更時に個別行高が正しく保持・破棄されること
- 無効な値が指定されたときに例外となること

## 9. 未決定事項

- 大規模データに対する性能目標と測定条件
- 表示範囲の前後に行を追加するオーバースキャンの要否と行数
- スクロール位置の補正をエンジンとコントロールのどちらが担うか
- 浮動小数点の誤差を考慮した行境界比較の許容差

## 10. 既存実装との移行メモ

- `GetVisibleRange` の `EndIndex` は、包含ではなく排他的なインデックスとして扱う。
- 現在のテストでは終了インデックスを包含する期待値があるため、この仕様を採用する際はテストを半開区間の期待値に更新する。
